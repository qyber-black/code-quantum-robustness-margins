# The environment the published results were computed in.
#
# pyproject.toml keeps floors so the library installs anywhere; this file
# pins what the numbers in results/ and in the papers were produced with,
# and `make venv` installs from it. Regenerate with
#   .venv/bin/python -m pip freeze > requirements-repro.txt
# after deliberately moving the environment, and expect the open-system
# results to move with it.
#
# Pinning versions is necessary and was not sufficient: the same versions
# produced open-system numbers differing by 4e-5 relative, because the SDP
# solver was left to cvxpy to choose. That is fixed separately, by naming
# the solver in lindblad.DEFAULT_SDP_SOLVER. Both are needed.
#
# The solver stack -- cvxpy, clarabel, scs, osqp, qdldl, highspy -- is the
# part that moves certified diamond norms. numpy and scipy move results in
# their last bits. The tooling pins (ruff, miss_hit, pytest) only keep the
# checks from changing under the code.
